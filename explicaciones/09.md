# Explicaciones del miniproyecto 9

## Campo columna y medida

Una columna contiene valores por fila; una medida devuelve un resultado evaluado con el contexto actual.

**Ejemplo:** Sucursal sirve para categorías; Ingresos es una medida que agrega transacciones.

**Cuándo se usa:** Decide qué campo describe el eje y qué medida cuantifica el resultado.

**Error frecuente:** Sumar un identificador numérico como si fuera un importe.

## Eje valores leyenda y detalle

Los contenedores definen el papel del campo en cada visual. Sus nombres y disponibilidad dependen del tipo y versión.

**Ejemplo:** En barras, Sucursal define categorías e Ingresos longitudes. La leyenda puede separar series.

**Cuándo se usa:** Revisa el tipo de visual antes de asignar campos; cambiarlo puede requerir otra configuración.

**Error frecuente:** Arrastrar campos sin revisar el agregado o el contenedor en que quedaron.

## Dispersión y unidad del punto

Los ejes muestran dos magnitudes; una categoría o campo de detalle puede separar las unidades observadas.

**Ejemplo:** Sin Sucursal, el ejercicio muestra un punto agregado. Con ella muestra cuatro puntos.

**Cuándo se usa:** Declara si cada punto es sucursal, producto, persona u otra unidad.

**Error frecuente:** Interpretar un punto agregado como si representara todas las observaciones individuales.

## Barras líneas e histogramas

Barras comparan categorías, líneas representan una secuencia ordenada e histogramas muestran frecuencias por intervalos numéricos.

**Ejemplo:** Un histograma de Ingreso cuenta cuántas operaciones caen en cada intervalo.

**Cuándo se usa:** Elige el visual por la estructura de los datos y la pregunta que debe resolver.

**Error frecuente:** Usar suma de importes como frecuencia o conectar categorías sin orden con una línea.

## Filtrar y resaltar

Filtrar restringe el conjunto que evalúa el destino; resaltar destaca una parte conservando una referencia visual más amplia en objetos compatibles.

**Ejemplo:** Elegir Norte puede filtrar una línea y resaltar una parte de unas columnas.

**Cuándo se usa:** Configura la interacción desde cada origen hacia cada destino.

**Error frecuente:** Pensar que cambiar una interacción afecta automáticamente todas las parejas de visuales.

## Escalas unidades y etiquetas

Escalas y unidades determinan cómo se lee un visual. La forma gráfica debe corresponder a los valores mostrados.

**Ejemplo:** En barras, una base cero permite comparar longitudes; una tabla puede mostrar el importe exacto sin abreviarlo.

**Cuándo se usa:** Declara unidades y usa etiquetas o información emergente cuando aporten precisión.

**Error frecuente:** Comparar longitudes de gráficos con escalas distintas sin advertirlo.

## Por qué se hace cada paso

1. El tipo de visual determina qué contenedores y representación necesita.
2. La categoría divide el conjunto; la medida cuantifica cada parte.
3. Cambiar el tipo requiere revisar de nuevo los campos y sus papeles.
4. Detalle define cada punto; sin él puedes ver un único agregado.
