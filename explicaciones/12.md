# Explicaciones del miniproyecto 12

## Página informe y tablero

Un informe de Power BI puede contener varias páginas. Un dashboard del servicio tiene otra función y no equivale simplemente a cualquier página con tarjetas.

**Ejemplo:** Resumen, Mapa y Detalle son páginas del informe de este ejercicio.

**Cuándo se usa:** Nombra el entregable y el lugar donde se va a consumir para elegir navegación y distribución.

**Error frecuente:** Llamar dashboard a todo y asumir las mismas funciones en Desktop y el servicio.

## Guardar publicar compartir

Guardar conserva un archivo o estado. Publicar envía contenido a un destino del servicio. Compartir concede acceso bajo sus condiciones.

**Ejemplo:** Entregar un PBIX no crea automáticamente un informe accesible por enlace.

**Cuándo se usa:** Prueba el acceso con la identidad y permisos del destinatario.

**Error frecuente:** Dar por hecho que publicar concede acceso a cualquier usuario.

## Actualización y credenciales

Actualizar consulta las fuentes según las conexiones disponibles. En el servicio deben resolverse credenciales, rutas y acceso.

**Ejemplo:** Una ruta local de Desktop puede requerir una estrategia distinta para actualización en el servicio.

**Cuándo se usa:** Documenta propietario, periodicidad, acceso y controles de completitud.

**Error frecuente:** Interpretar una fecha de actualización reciente como garantía de que todas las fuentes estaban completas.

## RLS y Ver como

RLS aplica restricciones por filas en condiciones de acceso compatibles. Ver como ayuda a probar roles, pero no sustituye revisar permisos reales.

**Ejemplo:** El rol Norte limita la práctica a 27000. En este simulador solo demuestra un filtro y no establece seguridad real.

**Cuándo se usa:** Prueba roles y accesos con identidades representativas en el entorno final.

**Error frecuente:** Esperar que un usuario con permisos elevados quede restringido como un Viewer.

## Rendimiento y equivalencia

Una mejora debe conservar el resultado y medirse con condiciones comparables. El tiempo percibido depende de consultas, origen y renderizado.

**Ejemplo:** Compara un visual antes y después con los mismos filtros y documenta caché y condiciones.

**Cuándo se usa:** Usa las herramientas de rendimiento disponibles y conserva controles numéricos.

**Error frecuente:** Concluir que una fórmula es más rápida solo porque tiene menos caracteres.

## Exportar configuración y PBIX

El JSON del taller registra opciones del simulador. Un PBIX contiene elementos propios del modelo e informe de Power BI.

**Ejemplo:** La descarga del proyecto 12 conserva el estado didáctico; no puede abrirse como un informe PBIX.

**Cuándo se usa:** Usa el JSON para revisar la práctica y construye el entregable real siguiendo los pasos de Desktop.

**Error frecuente:** Renombrar una extensión esperando convertir el archivo a otro formato.

## Por qué se hace cada paso

1. Visitar las páginas comprueba destinos distintos del informe.
2. El rol restringe el ejemplo a una unidad; no establece seguridad fuera de esta simulación.
3. Verificar27000 comprueba el efecto numérico del filtro.
4. Exportar conserva la configuración didáctica en JSON, no crea un PBIX.
