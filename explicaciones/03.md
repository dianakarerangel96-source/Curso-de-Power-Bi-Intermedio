# Explicaciones del miniproyecto 3

## Segmentador y filtro

Un segmentador es un visual que permite seleccionar valores. Los filtros también pueden aplicarse a visual, página o informe.

**Ejemplo:** Seleccionar Norte y Sur reduce las sucursales visibles en la práctica.

**Cuándo se usa:** Da controles al usuario y declara qué alcance tiene cada selección.

**Error frecuente:** Confundir un segmentador oculto con un filtro desactivado.

## ALL y ALLSELECTED

ALL puede quitar los filtros del conjunto indicado. ALLSELECTED es útil para evaluar el universo visible manteniendo selecciones externas según el contexto.

**Ejemplo:** Norte ocupa puesto 2 entre cuatro sucursales, pero puesto 1 cuando el universo seleccionado es Norte y Sur.

**Cuándo se usa:** Compara ranking global y ranking seleccionado para aprender qué universo responde a la pregunta.

**Error frecuente:** Usar ambas funciones como equivalentes o quitar filtros de tablas completas sin revisar efectos.

## RANKX y empates

RANKX calcula posiciones evaluando una expresión sobre una tabla. El orden y la opción de empates determinan los puestos.

**Ejemplo:** Con valores 32000,27000,23000 y 18000, Norte tiene posición 2 en el conjunto completo.

**Cuándo se usa:** Declara tabla comparada, dirección y empates densos o con salto.

**Error frecuente:** Mostrar una posición sin indicar qué sucursales participaron en el ranking.

## CALCULATE

Evalúa una expresión con contexto de filtro modificado. Es una pieza central para cambiar el alcance de una medida.

**Ejemplo:** El denominador de participación puede quitar sucursal conservando el periodo.

**Cuándo se usa:** Cuando necesitas agregar, reemplazar o retirar filtros de forma explícita.

**Error frecuente:** Entender CALCULATE como un simple sumador que no cambia filtros.

## Tabla desconectada y SELECTEDVALUE

Una tabla sin relación física puede servir de selector. SELECTEDVALUE obtiene un valor único del contexto o una alternativa cuando no hay uno solo.

**Ejemplo:** Un selector de indicador contiene Ingresos y Margen; una medida decide qué expresión evaluar.

**Cuándo se usa:** Parámetros y elecciones de presentación que no describen directamente una fila del hecho.

**Error frecuente:** Esperar que un selector desconectado filtre ventas sin ninguna medida que lo interprete.

## TREATAS y KEEPFILTERS

TREATAS proyecta valores como filtros sobre otras columnas. KEEPFILTERS puede intersectar un filtro con el existente en lugar de sustituirlo.

**Ejemplo:** Un selector de claves puede proyectarse sobre SucursalID. Equipos intersectado con Servicios no tiene coincidencias.

**Cuándo se usa:** Filtros virtuales y reglas de intersección cuando una relación física no es el diseño apropiado.

**Error frecuente:** Crear filtros virtuales para disimular claves mal definidas o ignorar tipos y valores sin correspondencia.

## Por qué se hace cada paso

1. Elegir el subconjunto define las unidades visibles.
2. ALLSELECTED permite comparar dentro de la selección externa del ejemplo.
3. Comprobar las posiciones valida el universo y la dirección descendente.
4. ALL permite contrastar las posiciones respecto al conjunto completo.
