# Proyecto 2 · Escribe tu primera medida

Escribe una medida, calcula su resultado y cambia el filtro para ver su contexto.

Tiempo sugerido: 20 minutos.

## Abrir el taller

Abra docs/laboratorio.html y seleccione el proyecto.

## Misión

1. Evalúa Ingresos = SUM(Ventas[Ingreso]).
2. Evalúa Utilidad = [Ingresos] - [Costos].
3. Evalúa Margen = DIVIDE([Utilidad], [Ingresos]).
4. Filtra Norte y observa margen 35.56 %.

## Pista

Utiliza la barra de fórmulas y Evaluar. Este ejercicio reconoce únicamente las tres expresiones indicadas.

## Repetir en Desktop

Modelado → Nueva medida. Crea las tres medidas por separado; crea también Costos = SUM(Ventas[Costo]). Pon las medidas en tarjetas y agrega un segmentador de sucursal.

Datos: docs/descargas/Base_minima.csv

El taller es una simulación con operaciones limitadas. No ejecuta DAX general, no genera PBIX y no reproduce íntegramente todos los paneles de Microsoft.
