# Publicar el curso en GitHub Pages

1. Cree un repositorio nuevo con el nombre curso-power-bi-gerencial, o use uno autorizado. Elija conscientemente su visibilidad. GitHub Free permite Pages en repositorios públicos; otras condiciones dependen del plan.
2. Suba el contenido de esta carpeta conservando docs, modulos y dax. No suba únicamente el ZIP. Asegúrese de incluir docs/index.html y los archivos de assets y descargas.
3. En el repositorio abra Settings > Pages. En Build and deployment seleccione Deploy from a branch. Elija main y /docs, y guarde.
4. Espere a que termine la publicación. La dirección aparecerá en Settings > Pages. No se puede conocer la URL definitiva hasta identificar la cuenta y el repositorio.
5. Abra la URL desde otra ventana y pruebe navegación, descargas y autoevaluación.

GitHub Pages sirve archivos estáticos. Publicar desde un repositorio privado no implica que el sitio sea privado; las opciones de acceso dependen del plan y la organización. No publique materiales confidenciales ni datos personales. Este curso contiene solo datos ficticios.

Documentación oficial consultada el 17 de octubre de 2026:
https://docs.github.com/es/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

Para actualizar una lección, edite su fuente y mantenga sincronizados los contenidos de modulos y docs/assets/course.js. Los archivos .md son la versión legible del repositorio; course.js alimenta la web.
